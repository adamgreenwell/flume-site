# Code of Conduct

This project follows the [Contributor Covenant][covenant] 2.1, the same Code of
Conduct as the Flume application. The full text, including the enforcement
guidelines, lives in the app repository:

**[adamgreenwell/flume → CODE_OF_CONDUCT.md](https://github.com/adamgreenwell/flume/blob/main/CODE_OF_CONDUCT.md)**

It applies here in full — issues, pull requests, and discussions on this
repository included.

One copy rather than two, because a Code of Conduct that has drifted between
repositories is worse than useless: it invites an argument about which version
was in force.

## Reporting

Report unacceptable behaviour to **adamgreenwell@gmail.com**. All reports are
handled confidentially.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
